# Code of Conduct

This project is for a welcoming sim racing and DIY hardware community.

## Expected behavior

- Be respectful and constructive.
- Assume good intent.
- Keep discussions focused on the project.
- Help beginners when possible.
- Give actionable feedback without personal attacks.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without permission.
- Spam or off-topic promotion.
- Repeatedly derailing technical discussions.

## Reporting

Use GitHub issues or repository moderation tools to report problems. Maintainers may remove comments, close issues, or block users to keep the project healthy.
