### Counting and normalization rules

- A **field** is one unique named live variable, app compatibility/derived alias, or SessionInfo leaf/container explicitly consumed by the local sources. A CarIdx array counts once regardless of length; each named LF/RF/LR/RR channel counts once before normalization.
- A **concept** groups aliases, decoded bitfields, vector axes, tyre zones and per-corner/per-car families that should be represented by one component family.
- Source tags in the table: **SDK** = exact name in an official local sample app; **map** = `IRACING_VARIABLES`; **provider** = read by `provider.ts`; **YAML** = SessionInfo property parsed by the app.
- Names tagged only `map`/`provider` are not asserted to be statically guaranteed by the SDK extract. The runtime `irsdk_varHeader` (`name`, `desc`, `unit`, `type`, `count`) remains authoritative for a loaded car/session.
- Live variables update at the SDK header's `tickRate`; the SDK notes describe normal 60 Hz / ~16 ms delivery and permit other reported rates. SessionInfo YAML changes on `sessionInfoUpdate`.

### Important source corrections / availability constraints

- `Speed` is raw m/s and is converted to km/h by the provider.
- `OilPressure` is normalized to kPa by the provider; the current catalog's `bar` label is not used here.
- `FuelUsePerHour` is handled as kg/h. `FuelUsePerLap` is app-derived kg/lap; no litres conversion exists.
- iRacing live/hot tyre pressure is unavailable in these local sources. Only `*coldPressure` is authoritative; `*pressure` catalog aliases are excluded.
- iRacing exposes no native TC-intervention Boolean here; `tcActiveDerived` is an app approximation.
- `FlagGreenWhiteCheckered` is an app pseudo-field; `irsdk_defines.h` has no direct GWC bit.
- Per-car arrays are always planned as one aggregate/parameterized relative, radar or standings component, never one widget per index.

### Variant design contract

- **Competition:** glanceable, deterministic, configurable operating bands, minimal decoration.
- **Futuristic-plausible:** short history, track ribbons, vector traces and projections grounded in real data; no ornamental sci-fi.
- **Bosch-DDU-inspired:** compact numeric cells, condensed/monospace type, explicit units and tell-tales; inspiration only, no copied proprietary artwork.
- Critical bands must remain car/team configurable unless an SDK enum/bit defines the state. The inventory intentionally does not invent universal temperature, pressure or fuel thresholds.
