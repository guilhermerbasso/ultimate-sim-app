# ref-touch-button-styles  (touch controls)
Reference: refs/ref-touch-button-styles.png

## Purpose
Design target for the Touch Controls "widgets" = clickable BUTTON/control STYLES (the touch equivalent of showing the
same action many ways). Flow: gpt-image -> base image -> build clickable touch dash of buttons -> QA vs reference until
clean. Themed per-car variants follow. Touch-friendly: large hit targets, clear pressed state, 1024x600-friendly.

## American-English prompt (validated)
A clean modern sim-racing TOUCHSCREEN button-box UI reference sheet on a dark near-black background, flat top-down UI,
showing a grid of DISTINCT touch control STYLES, each large and finger-friendly with a crisp label: (1) round momentary
push button, (2) square momentary button, (3) two-state toggle switch (on/off), (4) horizontal rocker (+/-), (5) rotary
encoder knob with a value ring, (6) LED-ringed illuminated button, (7) flip-cover guarded button (safety cover up),
(8) multi-position rotary selector (MAP 1-6). Label them with real functions: PIT, LIMITER, TC+, TC-, ABS, MAP, RADIO,
BOOST. Emissive cyan/amber accents on dark, subtle glass/metal feel, rounded corners, soft glow, clear pressed/active
highlight. No physical wheel, no car, no clutter, thin gray captions under each style. Crisp, high contrast, high
fidelity. US English only.

## Checklist notes
- Subject: 8 distinct touch control styles (momentary round/square, toggle, rocker, rotary encoder, LED button, guarded, selector).
- Data/values: race functions PIT/LIMITER/TC/ABS/MAP/RADIO/BOOST; clear active/pressed states.
- Layout/sizing: grid of large finger-friendly controls, touch 1024x600-friendly.
- Theme: clean button-box / wheel-plate, glass+metal, emissive on dark.
- Color rules: cyan/amber accents; green/active highlight when engaged.
- AVOID (app output): no titles beyond the function label, dark bg, minimal chrome, no clutter/overlap.

## QA outcome
- Image QA: pass — 8 distinct touch control styles (round/square momentary, toggle, rocker, rotary encoder+ring,
  LED-ringed, flip-cover guarded, multi-position selector) each with normal/pressed/active states, touch-friendly,
  labeled PIT/LIMITER/TC/ABS/RADIO/BOOST/MAP. Strong base for touch button widgets.
