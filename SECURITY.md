# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or open a private maintainer communication channel if enabled for the repository. Do not disclose exploitable details publicly before maintainers have had a chance to investigate.

## Scope

Relevant issues include:

- unsafe Electron behavior,
- arbitrary file read/write,
- command execution,
- credential exposure,
- malicious release artifacts,
- unsafe update or installer behavior.

## Secrets

Do not commit API keys, passwords, private keys, certificates with private key material, OAuth tokens, cookies, or `.env` files.
